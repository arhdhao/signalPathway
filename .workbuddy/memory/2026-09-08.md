### 设计要点（可复用于后续科普文档）
- **统一比喻贯穿全文**：把细胞比作「一栋楼」——配体=钥匙/送信人，受体=锁/信箱，
  第二信使=屋里的扩音广播，蛋白激酶=盖章员（磷酸化=盖章），级联放大=一圈圈扩大的涟漪，
  信号终止=三道刹车。同一个比喻从头用到尾，比每段换一个比喻好记得多。
- **主动讲特例**：NO 是气体、脂溶性、能穿膜，所以受体在细胞内（sGC），
  与"配体→细胞表面受体"的常规模型不同。主动点破这个反差，比回避更有助于理解。
- **用"坏掉会怎样"讲因果**（第 9 站表格）：sGC 被抑制 / PDE5 过活跃 / PDE5 被抑制，
  各对应一个最终效果。这既是因果逻辑教学，也自然接上游戏里的三种药物。
- **结尾引导到游戏**：观战看负反馈、投西地那非看"松开刹车"、投 ODQ 看上游断裂。
  并明确声明「游戏是简化模型，不是精确仿真」，避免读者把游戏数值当真实浓度。

### 关键技术点（下次别踩）

### ★ arhdhao 选的远期方向：换 Gillespie 随机模拟
这次没做，但摸清了两道坎，已写进 `nocgmp/README.md` 和各层文件注释：

1. **`biology.ts` 的 effect 是桌游动词，不是化学计量**（第一道坎，且不在引擎里）。
   `activate/inhibit/produce/consume` 描述「游戏规则里这条边干什么」，
   Gillespie 要的是 `PKG + MLCP → PKG + MLCP_p` 这种「谁消耗、谁生成、各几个」。
   需要补 stoichiometry 字段或写「effect → 计量式」翻译表。
2. **tick 语义要改**：现在固定 TICK_MS=100（10Hz），Gillespie 是变步长事件驱动。
   render.js 动画 / CHART「每 2 tick 采样」/ UI 倒计时全要跟改 —— 渲染层工作量可能比引擎大。

顺带：`slots` 竞争性抑制在 Gillespie 里反而更自然（两底物竞争同一酶速率常数，
自然涌现，不用专门写 `_resolveConsume`）。
