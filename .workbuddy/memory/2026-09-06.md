# 2026-09-06

## nocgmp.js 按「四层架构」重构（只挪位置，不挪数字）

依据 `gifts/GPT建议的分子模板设计思路.md`，把 `src/pathways/nocgmp.js` 从
「VIEW / RULES / BIOLOGY / DRUGS / COPY 五块」重构为六层：

```
① VIEW        画布尺寸 / 坐标 / 配色 / 连线样式（label / negate / waypoints 归入此层）
② BIOLOGY     分子档案 + 反应拓扑，零数字
③ INTERACTION 标签密码表（TAGS，独立成层 —— 既非生物学也非动力学）
④ KINETICS    分 nodes（分子自身属性）与 reactions（反应属性）两张小表
⑤ GAME        RULES / METRICS / DRUGS / EDITABLE（editable 从节点里拆出来，属 Game）
⑥ COPY        文案
末尾组装车间：NODE_ORDER / REACTION_ORDER → map → clean() → NODES / REACTIONS
```

关键约束（踩过才懂）：
- `NODE_ORDER` / `REACTION_ORDER` 的顺序**不能重排**。反应结算顺序决定每 tick
  消耗随机数的先后，顺序一变整局推演结果就变了，哪怕参数一个没改。
- `clean()` 过滤 undefined 是必需的：引擎里 `MoleculeTemplate` / `Reaction`
  用 `Object.assign(默认值, 配置)` 建对象，配置里带 `undefined` 会把默认值覆盖掉，
  渲染时炸（例如 `waypoints` 变 undefined）。

验证方法（可复用）：把 `LEVEL_NO_CGMP` 深排序后 `JSON.stringify` 存快照，
重构前后 `diff` 比对 —— 比跑模拟更严格、更快定位漏搬字段。
本次结果：数据 diff 完全一致，10 种子结局分布一致，build + smoke 通过。

顺手更新了 `docs/代码阅读指南.md` 第 ② 站的行号表（原表还写着 198 行）。

## 发现的两个遗留病（本次没动，记着）

1. **节点级 `band` 是死参数**：`KINETICS.nodes.sGC.band = [0,85]` 引擎完全不读，
   引擎只认 `KINETICS.reactions[*].band`。后果是玩家在 sGC 上拖「命中频段宽度」
   滑块（ui.js PARAM_META 有定义、editable 也放行了）实际不改变模拟结果。
   要生效得改 `engine.js` 的 `_resolveReaction`，让它优先取来源节点的 band。
2. **`Molecule.isDrug` 无调用方**：`tpl.kind === 'drug'` 只在 getter 里定义，没人用。

## 配平现状（基线，供后续对照）

`node tools/balance.mjs sweep`（10 种子）：
- 不干预 → none ×10
- 西地那非@25s → homeostasis ×10
- 西地那非@15s → homeostasis ×9 / none ×1
- 硝酸甘油×3 → homeostasis ×10  ← ⚠️ 设计意图是「应当死于 GTP 枯竭」，对不上
- 西地+硝甘 → homeostasis ×6 / toxicity ×4

即：死法 A（能量枯竭）目前打不出来，硝酸甘油过量反而能通关。
这是 engine.js `_judge` 上方 TODO 里「配平暂缓」的那部分，与本次重构无关。

## engine.js 解耦：引擎不再认识任何分子名（只搬数据，不改数值）

把第一关专属的"魔法数字 + 魔法文本"从引擎抽到 `nocgmp.js`，引擎改成读关卡配置。

**引擎侧改动（src/engine.js）**
- 新增 `TUNING` 常量块（Buff 衰减倍率 / 抖动幅度 / 激活满值 100 / 快照与历史上限等），
  原散落的魔法数字全部具名。
- `_updateMetrics()`：按 `m.kind` 驱动（driven / mirror / derived），不再 `if (m.id==='Ca')`。
- `_judge()`：整份胜负配方读 `level.outcome`（win / starve / toxicity / timeout 四形状），
  阈值、分子名、安全前置全在关卡；`safe` 前置用 `win.safe` 数组 + `_checkSafe()`。
- `_finish()`：结算文案读 `level.outcomeText[reason]`，运行时数字用 `fillTemplate` 填 `{占位符}`。
- `_snapshot()`：按 `level.chart.series` 采样，引擎不再写死采 Ca/cGMP。
- `produce` 消耗哪个资源池由 `rx.costPool` 决定（不再写死 GTP）。

**关卡侧补充（src/pathways/nocgmp.js）**
- `METRICS` 加 `kind / min / max`（Ca=driven 0–200，cGMP=mirror）。
- 新增 `CHART`（量程 max + series 曲线列表）、`OUTCOME`（四结局配方 + safe 前置）、
  `COPY.outcomeText`（四段结算文案，带 {metric}/{value}/{redline}/{seconds}/{pool} 占位符）。
- `reactions.r2` 加 `costPool:'GTP'`。
- 组装车间导出时派生 `goal / redline / timeout`（从 OUTCOME 反推），仅为兼容 ui.js/render.js；
  真正的唯一数据源是 `OUTCOME`。

**render.js / ui.js 跟进**：图表纵轴量程、曲线、Ca 仪表盘目标线、结算规则说明窗、时钟总秒数
全部改读 `level.chart / goal / redline / timeout / outcomeText`。

**验证（可复用，比跑模拟更严格）**：写 `tools/_trace.mjs` 把 7 场景×8 种子逐帧状态 dump 成文本，
重构前后 `diff` 比对 —— **逐帧完全一致**。配平 5 场景结局分布逐位相同。build + smoke 全绿。
（验证脚本与 .trace 临时文件已清理，未进仓库。）

**结论**：做第二关现在可"复制 nocgmp.js 改数据、引擎一行不动"。遗留技术债还剩一处：
`render.js` 的 `_drawEndothelium` 仍写死 `sim.node('NO')`（第一关专属视觉，本次未动）。

## 源码迁入 TypeScript（engine + 关卡全面类型化）

按讨论敲定的路 B（真 TS + tsc 编译回单 HTML），把逻辑核心迁成 TS，工具链从"纯 JS + build.js"
升级为"tsc 类型检查 → 编译到 build/ → build.js 打包单 HTML"。

**改动清单**
- `src/engine.js → engine.ts`：加 ~150 行领域类型接口（LevelConfig / MoleculeTemplateConfig /
  ReactionConfig / MetricConfig / DrugConfig / OutcomeConfig / ValueRef / SafeCondition / Buff /
  Outcome / 各 effect/kind 字面量联合），RNG / MoleculeTemplate / Molecule / Reaction / Simulator
  五类补显式字段声明 + 方法签名。运行时逻辑零改动（TUNING 常量逐位核对）。
- `src/pathways/nocgmp.js → nocgmp.ts`：`LEVEL_NO_CGMP: LevelConfig` 绑定类型；六层数据常量
  各配一层类型别名（NodeLayout/NodeBio/NodeKin/RxBio/RxKin/RxView）保留字面量（role/effect/drive
  不被拓宽）+ 支持组装车间字符串索引。数据本体 61 行变更里全是类型标注，数值未动。
- 新增 `package.json`（scripts: typecheck/build:ts/watch/build/smoke/check）、`tsconfig.json`、
  `.gitignore`（node_modules/、build/ 不入库）。
- `tools/build.js`：模块源从 `src/` 改指 `build/`（CSS/HTML 模板仍从 src 读）。
- `tools/balance.mjs` + `sweep.mjs`：import 改指 `../build/*`（引擎源已不在 src）。
- `src/dev.html`：加载 `build/main.js`（浏览器跑不了 .ts），dev 配合 `tsc -w`。

**tsconfig 关键取舍**：`strictPropertyInitialization:false`（字段走 Object.assign 默认值初始化，
tsc 追不到）；`verbatimModuleSyntax` + `allowJs`(checkJs:false) + moduleResolution:bundler，
让 .js 里 `import './engine.js'` 在 tsc 编译时解析到 engine.ts。

**验证**：tsc --noEmit 全量 0 错误；balance.mjs 五场景结局分布与原 JS 完全一致（确定性种子）；
smoke 7200 帧全绿。类型拦截实证：把关卡 effect 拼成 'consum'，tsc 报 TS2820 并提示
"Did you mean 'consume'?"——这正是转 TS 的核心价值（第二关数据字段拼错编译期当场拦）。

**迁移策略反思**：render/ui/main 三个 DOM/Canvas 层暂未迁 TS（收益中等、侵入大、还挂着
_drawEndothelium 写死 NO 的技术债）。要迁时把 .js 改 .ts + 补类型即可，tsconfig 已 allowJs，
无需改构建链。
