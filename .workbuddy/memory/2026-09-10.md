### 踩到的两个坑（写 .bat 通用教训）
1. **bat 内容必须纯 ASCII**：脚本正文一旦有中文，cmd 默认 936 代码页下会乱码；
   用 `chcp 65001 >nul` 切 UTF-8 后，多字节字符又会让 cmd 按字节偏移读文件时错位。
   所以正文全英文 + `chcp 65001`（让 node 输出的中文正常显示）是唯一稳的组合。
   文件名用中文没问题。
2. **换行必须是 CRLF**：Write 工具写出来是 LF，cmd 解析带括号块/label 时会抽风，
   写完要 `sed -i 's/\r$//; s/$/\r/'` 转一遍。
3. 便携性靠 `cd /d "%~dp0"`（切到脚本自身目录，且跨盘符有效）。

### 环境事实
- 本机 `node_modules` 当时是**不存在**的（build/ 也没有），已 `npm install` 补上（1 个包 = typescript）。
  换机器/清过目录后再跑脚本会自动装。
- 沙箱里 **cmd.exe 被安全策略拦截**，不能从 Bash/PowerShell 调用；测 .bat 只能手动跑等价命令验证。
