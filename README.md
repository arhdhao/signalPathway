# 信号通路模拟器

一个跑在浏览器里的细胞信号转导模拟游戏。玩家投放抑制剂 / 激活剂，
在信号网络里找关键枢纽，把失控的细胞拉回稳态。

> 尚在制作中。目前只有第一关：NO–sGC–cGMP–PKG–PDE5 血管舒张通路（西地那非那条）。

---

## 想直接玩？

打开 **`dist/信号通路模拟器.html`** —— 双击，用浏览器打开就行。
不需要装任何东西，也不需要联网，拷给别人也能跑。

---

## 这个文件夹里都有什么

| 文件夹 / 文件 | 是什么 | 用得着吗 |
|---|---|---|
| `dist/信号通路模拟器.html` | **游戏本体**，一个文件包含全部内容 | ✅ 只玩的话看这个 |
| `docs/` | 说明书，按读者分了三类 | 📖 想了解原理时看 |
| `设计资料/` | 最初的想法草稿 + 外部 AI 给的评审和建议 | 📖 好奇项目怎么来的可以看 |
| `一键编译.bat` | 双击 = 把源码重新打包成上面那个 HTML | 🔧 改了代码才用 |
| `参数配平.bat` | 双击 = 跑 5 个场景，检查关卡数值是否平衡 | 🔧 改了数值才用 |
| `src/` | 程序源码（.ts / .js） | ❌ 不懂代码可无视 |
| `tools/` | 给开发用的小脚本（配平、打包、测试） | ❌ 不懂代码可无视 |
| `package.json` / `tsconfig.json` | 工具链的配置文件 | ❌ |
| `node_modules/` `build/` | 依赖库和编译中间产物，自动生成、不入库 | ❌ |

一句话：**想玩游戏就开 `dist/` 里的 HTML；想改东西才需要碰别的。**

## 懒人入口（Windows 双击即可）

| 文件 | 作用 |
|---|---|
| `一键编译.bat` | 类型检查 → 打包 `dist\信号通路模拟器.html` → 冒烟测试 |
| `参数配平.bat` | 先重新编译，再跑 `tools/balance.mjs` 的 5 个场景 |

两个脚本都会自动切到自身所在目录，所以放在哪台电脑、哪个路径下都能用。
换电脑后第一次运行会联网执行 `npm install`（`node_modules/` 不入库），装一次即可。
前置条件只有一条：装了 Node.js 18+（https://nodejs.org）。
