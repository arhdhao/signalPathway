1. 直接修改 关卡文件 中的参数，
   然后打开 dist 中的 信号通路模拟器 HTML 文件，并不会生效。
   因为没有 编译 关卡文件，所以修改后的参数不会被加载。

2. 标准做法是在 关卡文件 中改好参数，保存
   终端运行：node tools/build.js
   刷新浏览器里打开的网页

3. 还有个简便方法
   运行 dev.html 开发模式网页

4. 具体方法是
   cmd 中 cd /d C:\Users\arhdy\WorkBuddy\signalPathway
   运行： node tools/dev-server.mjs
   打开浏览器，输入 http://localhost:8123/src/dev.html
   就可以查看开发模式网页了。
