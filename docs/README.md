# 说明书导航

按「你是谁」分了三个文件夹，进对应的那个就行。

| 如果你…… | 去这里 | 里面有 |
|---|---|---|
| 只是想玩懂这个游戏 | [`给玩家/`](给玩家/) | 细胞信号通路入门 |
| 想改关卡数值 / 做新关卡 | [`给关卡作者/`](给关卡作者/) | 生化反应动力学、参数调参清单 |
| 想改程序本身 | [`给开发者/`](给开发者/) | 模拟机制介绍、代码阅读指南、构建脚本改造备忘 |

## 推荐阅读顺序

- **零基础** → `给玩家/细胞信号通路入门.md`（讲「谁作用于谁」）
- **想改数值** → 先读上面那篇 → `给关卡作者/生化反应动力学.md`（讲「多快、多强」）
  → `参数调参清单.md`（哪些能随手改，哪些一改就变味）
- **想改代码** → `给开发者/代码阅读指南.md`（文件结构与阅读顺序）
  → `模拟机制介绍.md`（引擎具体怎么算）

> 同一个问题在这三份文档里是三个层次：
> 入门讲**拓扑与因果**，动力学讲**速率与参数**，机制介绍讲**代码怎么实现**。
> 写新文档前先想清楚它落在哪一层。

## 关卡自带的文档

第一关的说明和参数依据跟关卡数据放在一起，见 `src/pathways/nocgmp/`：

- `README.md` —— 这一关的文件结构
- `NO通路生物学参数设定.md` —— 参数背后的文献依据
- `修改关卡参数如何调试.md` —— 改完怎么验证

## 关于 `设计资料/`

项目根目录的 `设计资料/` 放的是早期构想和外部 AI 的评审意见，
属于「当时是怎么想的」，不是当前实现的说明书。别拿它当文档读。
