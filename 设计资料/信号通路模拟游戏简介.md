# 《细胞信号沙盒 (Cellular Sandbox)》游戏简介
**—— 信号通路模拟游戏与计算系统生物学**

## 一、 项目背景与核心愿景
《细胞信号沙盒》是一款运行在网页端的微观模拟策略游戏。
我们致力于打破硬核科学与娱乐的壁垒，将极度复杂的“计算系统生物学”降维成**逻辑解谜与塔防资源管理**玩法。

*   **核心玩法**：玩家将扮演微观世界的“主治医师”，面对癌变、病毒感染等失控的细胞网络，通过**投放靶向药物**、**调节枢纽节点参数**，在错综复杂的信号通路中寻找“负反馈”与“串扰”。
*   **过关目标**：阻断异常增殖信号，恢复系统动态平衡，最终维持宏观的【患者血条】稳态。
*   **技术栈**：纯 TypeScript 编写底层核心逻辑，基于 HTML5 Canvas / WebGPU 实现千军万马般的微观流体渲染。

---

## 二、 底层引擎架构 (Engine Architecture)
为了在网页端支撑百万级分子概念的实时交互，且保证逻辑的绝对严谨，我们设计了专用的**“微观状态机引擎”**：

1. **逻辑与渲染彻底解耦**
   *   **逻辑层（物理引擎）**：固定在 **10 TPS**（每秒执行 10 个 Tick 回合）。游戏本质上是一个高速运转的回合制系统，以极低的 CPU 消耗处理庞大的数值网络。
   *   **渲染层（视觉引擎）**：不设限（60 FPS），保障玩家视觉的绝对丝滑。
2. **双缓冲状态机 (Double Buffering) 消除时序Bug**
   *   所有分子实体拥有 `currentState`（当前状态）和 `nextState`（下回合状态）。
   *   在一个 Tick 内，所有分子的碰撞判定绝对并发（只读取当前状态，计算结果存入下回合状态），彻底消灭因数组遍历顺序导致的“幽灵先手Bug”。
3. **滑动窗口平滑视觉 (Ring Buffer)**
   *   拒绝生硬的 0（死）和 1（活）闪烁。渲染引擎会读取分子过去 10 个回合的活跃记录求取平均值，呈现出“呼吸灯”和“流体扩散”般高级的微观视觉效果。

## 三、 十大生物学游戏化法则 (Game Design Laws)
如何将枯燥的微积分方程变成好玩的游戏机制？我们确立了以下十条“粗粒化抽象”法则：

### 📁 【交互与战斗机制】
*   **法则1：三维折叠 $\rightarrow$ 密码标签 (Tags)**
    放弃复杂的蛋白质 3D 碰撞。分子间的识别简化为 `String[]` 标签对比，只有“锁”与“钥匙”的密码对得上，才能触发交互。
*   **法则2：微积分 $\rightarrow$ 离散概率 (Dice Roll)**
    抛弃晦涩的微分方程。分子能否成功激活下游，取决于每次 Tick 掷出的随机数是否落在目标的 `[Min, Max]` 接收区间内。
*   **法则3：微观数量膨胀 $\rightarrow$ 兵力与乘数 (Capacity & Amplify)**
    不渲染上百万个独立分子。用 `Capacity`（总兵力/浓度数值池）代表数量，配合枢纽分子的 `Amplify Factor`（暴兵乘数），完美模拟生物学中的“信号级联放大”现象。
*   **法则4：化学修饰 $\rightarrow$ RPG 状态 (Buffs & Timers)**
    复杂的磷酸化、泛素化过程，简化为带有倒计时的 RPG 状态（如 `Activated` 激活增益，`Muted` 沉默控制）。时间一到，状态自然褪去（模拟半衰期衰减）。

### 🌍 【环境与资源机制】
*   **法则5：空间距离 $\rightarrow$ 隔间与地形 (Compartments)**
    细胞被划分为膜、质、核等独立防区。引入“脂筏/支架蛋白”作为特殊地形，同处该地形的分子碰撞概率翻百倍；跨越防区则需触发带有 Timer 的转运倒计时。
*   **法则6：能量代谢 $\rightarrow$ 全局蓝条 (Global ATP)**
    所有的激酶“暴兵”和“掷骰子”都需要消耗全局 ATP（魔法值）。一旦蓝条耗尽，全屏信号陷入沉默。
*   **法则7：基因表达 $\rightarrow$ 兵营倒计时 (Spawn Delay)**
    转录与翻译过程，简化为数百个 Tick 的读条延迟。玩家会体验到“长线投资”后，目标蛋白瞬间“爆兵”的策略爽感。

### 🎮 【策略涌现与宏观反馈】
*   **法则8：绝对特异性 $\rightarrow$ 模糊重叠区间 (Side Effects)**
    信号接收频段允许微小的重叠。这种不完美自然涌现出了医药界最头疼的“药物脱靶”与“副作用”——玩家在治好一个病的同时，可能会按下另一个葫芦浮起一个瓢。
*   **法则9：参数敏二八定律 $\rightarrow$ 职业模板 (Hub Tuning)**
    为了降低玩家的认知负担，80% 的普通“传话分子”锁死基准参数；只开放 20% 的核心枢纽（Hubs）作为滑块，供玩家（或靶向药）进行数值调节。
*   **法则10：微观生死 $\rightarrow$ 宏观双血条 (HP Bars)**
    微观分子的容量（Capacity）变化，最终会溢出到"阈值池"中，直接反映在 UI 顶部的【疾病进展】（敌方进度）与【患者健康】（我方生命）双血条上，提供直观的过关反馈。

### 🧩 代码中已实现、但十条法则未提及的额外抽象

`nocgmp.js` 里还有一些抽象不在这十条法则内，但已经真实落地，值得补进架构文档：

*   **六层数据分离**（VIEW / BIOLOGY / INTERACTION / KINETICS / GAME / COPY）
    一个节点按"变化的动机"拆成六份：改坐标只碰 VIEW，改衰减只碰 KINETICS。这是工程层面最重要的抽象，比任何单条玩法法则都更影响可维护性。
*   **可配置四结局系统 `OUTCOME`**
    胜负从"引擎里写死的裸数字"升级为关卡声明的四类判定形状：稳态恢复（win）、能量枯竭（starve）、脱靶毒性（toxicity）、干预失效（timeout）。做第二关只需复制改数据。
*   **宏观指标通式 `METRICS.kind`**
    指标怎么算不再靠 `if (m.id === 'Ca')` 硬编码，而是由 `driven`（被效应器抽走+回归）/ `mirror`（镜像分子数量）/ `derived`（指标间换算）三种通式声明，引擎统一执行。
*   **资源池 + 药物系统 `DRUGS`**
    药物不是裸数字，而是可组合的 `effects`（`spawn` 投放 / `mute` 沉默 / `boostPulse` 放大脉冲 / `restore` 补充资源），并带 `metabolism` 药物代谢退出速率。
*   **反应结算顺序 `REACTION_ORDER`**
    结算顺序本身会消耗随机数、改变推演结果 —— 确保模拟的可复现性，属于比"离散概率"更底层的确定性约束。
*   **外部脉冲信源 `RULES.pulse`**
    唯一的系统外输入：内皮脉冲式喷发 NO（`period` / `amount` / `cap`）。这是负反馈环振荡的能量来源，与法则7的"输出延迟"方向相反，属于"输入节奏"。

## 四、 关卡敌人设计：AI与变异机制
游戏中的“反派（如癌细胞/突变节点）”并非单纯的数值堆砌，而是通过底层性格修正涌现出的病理灾难：
*   **效用打分与性格挂载**：正常细胞遵循系统设定的存活权重进行休眠与激活。而癌细胞/突变节点将被挂载 `Aggressive`（莽夫）性格修正系数 (Modifier)。
*   **行为变异**：它们会无视上游的“刹车（抑制）信号”，强行消耗 ATP 疯狂输出，掠夺资源，玩家必须通过精妙的药物组合才能将其镇压。

# 《细胞信号沙盒》游戏简介
## 五、 实战演示：NO-cGMP 新手村关卡（MVP 剧情剧本）

**【关卡背景 (Level Briefing)】**
*   **场景**：血管平滑肌细胞内部 (Vascular Smooth Muscle Cell)。
*   **当前病理状态**：血管平滑肌细胞内钙离子浓度过高会促进收缩（病理时可表现为痉挛，参与高血压或心绞痛）。
*   **过关条件**：降低细胞内钙离子浓度，实现平滑肌舒张。

### 1. 登场角色（分子图鉴与兵种设定）

在这一关卡中，微观状态机引擎将实例化以下几个核心兵种（概念池）：

*   **NO (一氧化氮) —— 【外部信号源】**
    *   **特性**：由上游内皮细胞呈“脉冲式”释放。无视细胞膜地形阻挡。带有 `NO_Signal` 对接密码。
*   **sGC (可溶性鸟苷酸环化酶) —— 【放大器】**
    *   **特性**：接收频段极窄（极难被随机碰撞激活）。但一旦与 NO 密码匹配并激活，具有极高的 `Amplify Factor`（暴兵乘数），能瞬间产出大量cGMP。
*   **cGMP (环磷酸鸟苷) —— 【次级信使】**
    *   **特性**：依靠庞大的基数（Capacity）去“淹没”并激活下游的信号分子。
*   **PKG (蛋白激酶G) —— 【输出核心】**
    *   **特性**：平时处于休眠状态。被 cGMP 激活后（挂载 `Activated` Buff，倒计时 50 Tick），它会执行双线任务：
        *   **主线输出**：疯狂磷酸化靶蛋白（效果是降低钙离子浓度）。
        *   **旁路反馈**：它会同时“唤醒” PDE5 信号分子。
*   **PDE5 (磷酸二酯酶) —— 【清道夫】**
    *   **特性**：初始休眠。一旦被 PKG 激活，它的唯一工作就是降解 cGMP ，其乘数为负数，大幅扣减 cGMP 的总量。

---

### 2. 系统动态演化（不加干预的自然状态）

如果玩家不进行任何操作，只在旁边“观战”，他们将看到引擎底层完美涌现出生物学中最经典的**“负反馈自限性（Negative Feedback Loop）”**：

*   **Tick 1-10 **：NO 脉冲进场，成功撞击 sGC。sGC 疯狂暴兵，`cGMP 总量` 呈指数级飙升。
*   **Tick 11-20 **：海量的 cGMP 成功激活了 PKG。PKG 给各个 靶蛋白 挂上 Buff 开始输出，玩家看到 UI 顶部的【钙离子浓度】开始下降，平滑肌逐渐舒张，胜利在望。
*   **Tick 21-30 **：由于 PKG 被大量激活，它触发了**旁路设定**——沉默的 PDE5 被全部唤醒！
*   **Tick 31-50 **：PDE5 开始以恐怖的效率降解 cGMP。cGMP 数量暴跌，无法继续维持 PKG 的 Buff。PKG 的激活倒计时归零，重新进入休眠。
*   **结果 (死局)**：由于 PKG 哑火，钙离子浓度再次反弹。玩家发现系统卡在了一个**“动态平衡”**的僵局里，血条永远只能打掉一半，无法过关。

---

### 3. 玩家破局与解谜时刻（The "Aha!" Moment）

*   **玩家操作**：玩家打开道具栏，细胞内投放靶向药：**【伟哥 (西地那非 / Sildenafil)】**。
*   **底层判定**：
    *   【伟哥】长得和 cGMP 非常像，它拥有和 cGMP 相同的 `PDE_Target` 密码标签，能被防御塔 PDE5 识别。
    *   **但是！** 伟哥的 `Amplify Factor`（乘数）为 0，且不具备被降解的属性。
*   **涌现出的结果**：
    *   伟哥以极高的浓度（Capacity）进入战场，凭借概率优势，瞬间**塞满了 PDE5 的所有运算槽位（占据了受体锁孔）**。
    *   PDE5 的物理引擎 Tick 全部浪费在了“咬咬不动的伟哥”上，导致它彻底“卡齿轮（被抑制）”。
    *   **负反馈回路被生生斩断！** sGC 继续生产的 cGMP 不再被降解，数量狂飙；PKG 获得了永久的激活 Buff，疯狂输出。
*   **关卡结算**：钙离子浓度断崖式暴跌，宏观血条瞬间被清空，平滑肌完全舒张。屏幕弹出：**【Level Cleared! 疗效显著】**。


### 💻 《细胞信号沙盒》NO-cGMP 核心逻辑演示代码

你可以直接把这段代码复制到任何 TypeScript/JavaScript 运行环境中（比如浏览器的 F12 控制台）直接运行。

```typescript
/**
 * 《细胞信号沙盒》 - NO-cGMP 新手村关卡引擎 Demo
 * 核心机制：双缓冲 (Double Buffering) + 宏观数值池 (Capacity Pool)
 */

// 1. 定义系统的状态池（双缓冲结构）
class SystemState {
    // 【兵力池 / 浓度池】
    cGMP_Capacity: number = 0;
    Viagra_Capacity: number = 0;
    
    // 【RPG Buff 倒计时】 (大于0表示激活)
    sGC_ActiveTimer: number = 0;
    PKG_ActiveTimer: number = 0;
    PDE5_ActiveTimer: number = 0;
    
    // 【宏观血条】 (目标是降到 0)
    Calcium_HP: number = 100; 
}

class CellularEngine {
    // 双缓冲：当前回合只读 currentState，计算结果写入 nextState
    public currentState = new SystemState();
    public nextState = new SystemState();
    
    // 关卡基准参数
    private sGC_Amplify = 30;     // sGC 每次激活产出 30 cGMP
    private PKG_Threshold = 40;   // cGMP 必须大于 40，才能激活 PKG
    private PDE5_Degrade = 50;    // PDE5 每次能绞杀 50 兵力的 cGMP
    private PKG_Heal = 8;         // PKG 激活时，每回合打掉 8 点钙离子血条
    private Disease_Rebound = 4;  // 疾病反弹：PKG未激活时，钙离子每回合涨 4 点

    public tick() {
        // --------------------------------------------------------
        // 阶段 1：根据当前状态，计算概率碰撞与数值变化（写入 nextState）
        // --------------------------------------------------------
        
        // 拷贝基础状态，准备覆盖
        this.nextState = { ...this.currentState }; 

        // 1. 【核心放大器 sGC】：如果激活，疯狂暴兵 cGMP
        if (this.currentState.sGC_ActiveTimer > 0) {
            this.nextState.cGMP_Capacity += this.sGC_Amplify;
        }

        // 2. 【次级信使 cGMP】：利用兵力优势尝试激活 PKG
        if (this.currentState.cGMP_Capacity >= this.PKG_Threshold) {
            this.nextState.PKG_ActiveTimer = 2; // 给 PKG 挂上 2 Tick 的激活 Buff
        } else {
            this.nextState.PKG_ActiveTimer = 0; // 兵力不足，PKG 哑火
        }

        // 3. 【输出核心 PKG】：主线降钙 + 旁路唤醒 PDE5
        if (this.currentState.PKG_ActiveTimer > 0) {
            this.nextState.Calcium_HP -= this.PKG_Heal; // 疯狂输出
            this.nextState.PDE5_ActiveTimer = 2;        // 唤醒防御塔 PDE5
        } else {
            this.nextState.Calcium_HP += this.Disease_Rebound; // PKG 哑火，病情反弹
        }

        // 4. 【防御塔 PDE5】：绞杀 cGMP (核心解谜点：竞争受体)
        if (this.currentState.PDE5_ActiveTimer > 0) {
            // 伟哥的竞争机制：计算 cGMP 在“所有能被 PDE5 识别的分子”中的占比
            let totalTargets = this.currentState.cGMP_Capacity + this.currentState.Viagra_Capacity;
            
            if (totalTargets > 0) {
                // 如果场上有伟哥，cGMP 被命中的概率会被无限稀释！
                let hitProbability = this.currentState.cGMP_Capacity / totalTargets;
                let actualDegrade = this.PDE5_Degrade * hitProbability; 
                
                this.nextState.cGMP_Capacity -= actualDegrade;
            }
        }

        // --------------------------------------------------------
        // 阶段 2：环境自然衰减（半衰期与越界保护）
        // --------------------------------------------------------
        
        // cGMP 自然衰减 (每回合流失 20%，防止无限膨胀)
        this.nextState.cGMP_Capacity *= 0.8;
        
        // 数值越界保护
        if (this.nextState.cGMP_Capacity < 0) this.nextState.cGMP_Capacity = 0;
        if (this.nextState.Calcium_HP > 100) this.nextState.Calcium_HP = 100;
        if (this.nextState.Calcium_HP < 0) this.nextState.Calcium_HP = 0;

        // Buff 倒计时自然衰减
        if (this.nextState.sGC_ActiveTimer > 0) this.nextState.sGC_ActiveTimer--;
        if (this.nextState.PDE5_ActiveTimer > 0) this.nextState.PDE5_ActiveTimer--;

        // --------------------------------------------------------
        // 阶段 3：回合交替，双缓冲覆写
        // --------------------------------------------------------
        this.currentState = { ...this.nextState };
    }
}
```

### 🎬 剧本模拟运行：见证“涌现”的奇迹

有了上面的引擎，我们就可以写一个主循环，来完美复现你设计的 4 个阶段。

```typescript

let isLevelCleared = false;

console.log("=== 🔴 关卡开始：高血压危机 ===");

// 模拟游戏进行 50 个 Tick (回合)
for (let tick = 1; tick <= 50; tick++) {
    
    // 【事件1】：Tick 1，内皮细胞脉冲释放 NO，击中并永久激活 sGC
    if (tick === 1) {
        console.log("\n[系统提示] 外部 NO 信号脉冲进场，sGC 放大器被激活！");

    engine.tick();

    // 格式化输出 UI (只打印关键节点，让你看清涨跌潮汐)
    if (tick % 2 === 0 || tick > 28) {

    }

    // 胜利判定
    if (engine.currentState.Calcium_HP <= 0 && !isLevelCleared) {

        isLevelCleared = true;
        break; 
    }
}
```

### 🧠 代码背后回答了你之前的哪些疑问？

通过这段代码，你可以非常清晰地印证之前困扰你的几个问题：

1. **实例数量（问题1）**：你看，没有几十万个对象，只有 `cGMP_Capacity` 和 `Viagra_Capacity` 几个数字，极大地节省了性能。
